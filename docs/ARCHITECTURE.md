# MeChat Architecture

Next.js App Router + TypeScript on Vercel, Neon PostgreSQL with Drizzle, Better Auth, Brevo. The AI provider adapter runs SERVER-SIDE behind authenticated endpoints. The frontend never receives credentials. Use server-sent token streaming, controlled context size, input validation and per-user budget guards. A modular monolith avoids unnecessary microservices.

**Status:** Backend design only; not connected in Phase 1.
